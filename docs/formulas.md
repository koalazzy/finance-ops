# FinanceOps 公式手册

> 所有计算均基于中国人民银行及商业银行现行标准

---

## 一、住房按揭

### 等额本息月供

```
M = P × r × (1+r)^n / [(1+r)^n - 1]

M = 月供
P = 贷款本金
r = 月利率（年利率 / 12）
n = 总期数（年 × 12）
```

**总利息 = M × n - P**

### 等额本金

```
每月本金 = P / n
第 k 期月供 = P/n + (P - (k-1) × P/n) × r
总利息 = P × r × (n+1) / 2
```

### 提前还款

```
剩余本金 = 原始本金按原方案偿还 k 期后的余额
节省利息 = 原方案剩余利息 - 新方案剩余利息 - 违约金
```

---

## 二、银行承兑汇票贴现

```
贴现利息 = 票面金额 × 贴现年利率 × 剩余天数 / 360
实际到账 = 票面金额 - 贴现利息
实际年化成本 = 贴现利息 / 实际到账 × 360 / 剩余天数
```

---

## 三、国内信用证

```
开证费   = 金额 × 0.05%-0.15%
通知费   = ¥200-500 (固定)
议付费   = 金额 × 0.1%-0.3%
承兑费   = 金额 × 月费率 × 月数
不符点费 = USD 50-100 (固定)
付款费   = 金额 × 0.1%-0.2%
电讯费   = ¥100-300 (固定)

综合成本率 = Σ费用 / 信用证金额 × 100%
```

---

## 四、结构性存款

```
保底收益 = 本金 × 保底利率 × 天数 / 365
高收益   = 本金 × 挂钩利率 × 天数 / 365
实际收益 = 触发条件满足 ? 高收益 : 保底收益
```

---

## 五、大额存单

```
利息 = 本金 × 年利率 × 期限年数
到期本息 = 本金 + 利息

对公起存: ¥1,000万
对私起存: ¥20万
```

---

## 六、协议存款

```
协定存款收益 = 基本额度利息 + 超额利息
基本额度利息 = 基本额度 × 活期利率 × 天数 / 360
超额利息     = 超额金额 × 协定利率 × 天数 / 360
```

---

## 七、货币基金

### 七日年化法（估算）
```
预期收益 = 本金 × 七日年化收益率 × 持有天数 / 365
```

### 万份收益法（精确）
```
日收益 = 份额/10000 × 当日万份收益
```

---

## 八、净值型理财

```
购买份额 = 申购金额 / 申购净值
赎回金额 = 份额 × 赎回净值
持有收益 = 赎回金额 - 申购金额 - 费用
年化收益 = 持有收益 / 申购金额 × 365 / 持有天数
```

费用包括：管理费(0.2-0.5%/年)、托管费(0.02-0.05%/年)、申购费(0-0.2%)、赎回费(0-0.5%)、业绩报酬(超额×10-20%)

---

## 九、国债

```
每年利息 = 面值 × 票面利率

二级市场到期收益率：
YTM = [年息 × 年数 + (面值 - 买入价)] / 买入价 / 年数
```

---

## 十、券商收益凭证

```
固定型：到期收益 = 本金 × 约定年化 × 天数 / 365
浮动型：到期收益 = 本金 × (固定+浮动) × 天数 / 365
```

---

> 以上公式为 FinanceOps 计算引擎的实现依据。
> 所有费率区间为市场参考值，实际以银行报价为准。
