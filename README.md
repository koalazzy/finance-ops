**打开即用，无需登录，不调后端，数据不出浏览器。**

🔗 **[立即使用](https://guaguatuna.github.io/finance-ops)**

## 📊 功能

### 🏠 住房按揭测算
- 等额本息 / 等额本金 双方案对比
- 提前还款损益（缩短期限 vs 减少月供）
- 利率 ±50bp 敏感性分析
- 前 360 期逐月还款计划

### 📄 银行承兑汇票贴现
- 贴息计算 + 实际到账金额
- 实际年化成本率
- 5 档贴现率自动对比

### 📜 国内信用证
- 全流程 8 项费用明细
- 综合成本率
- 与流动资金贷款横向对比

### 🏢 对公理财
- 结构性存款（保底/触发双场景）
- 大额存单（对公，¥1000 万起）
- 通知存款（1 天 / 7 天）
- 协定存款（分层计息）

### 👤 对私理财
- 定期存款 · 大额存单（¥20 万起）
- 货币基金（七日年化 & 万份收益）
- 净值型理财（穿透费率：管理费/托管费/申赎费/业绩报酬）
- 国债（一级 & 二级市场、免税对比）
- 券商收益凭证

## 🚀 使用方式

### 方式一：直接打开 GitHub Pages
```
https://你的用户名.github.io/finance-ops
```

### 方式二：本地运行
```bash
git clone https://github.com/你的用户名/finance-ops.git
cd finance-ops
# 用任意 HTTP 服务器打开，如：
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 方式三：嵌入企业微信/飞书/公众号
将部署后的 URL 配置为应用入口或公众号菜单即可。
